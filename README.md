# 校园寻物站

基于第一次原型设计的校园失物招领 WEB 程序，使用原生 HTML、CSS 和 JavaScript 实现。

## 主要功能

- 发布寻物信息和招领信息。
- 集中浏览，通过物品名称、地点或特征搜索。
- 按类型、类别、地点和状态组合筛选。
- 查看详情，一键复制发布者联系方式。
- 在“我的发布”中将本人信息标记为“已找到”或“已归还”。
- 自动保存发布草稿，适配电脑和手机布局。

## 运行方法

1. 点击仓库的 **Code → Download ZIP**，下载并解压全部文件。
2. 用 **Google Chrome** 打开根目录的 `index.html`，保留旁边的 `assets` 文件夹。
3. 网页运行无需安装依赖或启动服务器。

信息保存在当前浏览器中，不同电脑或浏览器之间不共享；发布者标识用于本机演示。

## 使用说明

首页点击“发布信息”，填写物品信息和联系方式后提交。通过首页卡片或搜索结果进入详情，复制联系方式后自行联系发布者。

物品找回或归还后，从“我的发布”进入详情，点击“标记已找到”或“标记已归还”，确认更新。首页默认显示未完成信息，选择“全部状态”或“已完成”可查看历史记录。

发布表单会提示必填项、日期和格式错误，并自动保存草稿；发布成功后清除草稿。若浏览器不允许自动复制联系方式，可按提示手动复制。

```text
  images/logo.svg             本地图标
tests/
  domain.test.cjs              业务规则测试
  storage.test.cjs             保存逻辑测试
```

## 单元测试

测试使用 Node.js 自带的 `node:test` 和 `node:assert/strict`。安装 Node.js 24 后，在仓库根目录运行：

```powershell
node --test tests/domain.test.cjs tests/storage.test.cjs
```

共 28 个测试用例，覆盖输入校验、搜索筛选、状态更新及存储异常。运行网页不需要安装 Node.js。
