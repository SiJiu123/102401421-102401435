# 校园寻物站

第二次软件工程结对作业的 WEB 实现，沿用第一次原型的绿色界面。支持发布寻物与招领、集中浏览、关键词搜索、查看详情和联系方式、发布者标记“已找到 / 已归还”。

## 运行方法

1. 下载完整程序目录。
2. 用 **Google Chrome** 打开 `index.html`。不能只下载这一个 HTML，旁边的 `assets` 必须保留。
3. 首次进入可看到六条预置演示记录，其中一条已完成。示例联系方式为虚构账号。
4. 点击右上角“发布信息”，选择寻物或招领，填写名称、类别、地点、日期和联系方式，点击发布。
5. 发布成功后进入详情；完成交还后，从“我的发布”打开自己的信息，点击“标记已找到 / 已归还”，确认更新。
6. 首页默认显示未完成信息。需要查看已找到、已归还的物品时，将“信息状态”切换为“已完成”或“全部状态”。

网页本身无需 Node.js、安装依赖、联网字体或服务器。若双击时默认打开其他浏览器，可右键 `index.html` → 打开方式 → Google Chrome。

## 保存范围

信息保存在当前浏览器的 localStorage，不同电脑、浏览器和无痕窗口间不共享；清除浏览器数据会清除发布记录。

发布者标识用于本机演示“只有自己可以更新”的流程，不是账号认证。真实多人使用需要增加共享存储和服务端权限校验。

浏览器对于直接打开的 `file://` 页面的存储行为可能不同。请保持文件位置和 Chrome 配置不变；如顶部出现无法保存的提示，不要反复发布或清除原数据。HTTP 预览和直接打开 HTML 的记录也不共用。

## 操作说明

- 搜索：物品名称、地点或特征均可匹配，自动去掉首尾空格，并统一英文大小写与全角字符。
- 筛选：类型、类别、地点和状态同时生效；点击“重置筛选”恢复默认条件。
- 联系：详情中点击“复制联系方式”；浏览器不允许自动复制时，会选中文字并提示手动复制。
- 发布：必填项缺失、无效或未来日期、过长文本、邮箱格式错误会提示原因。保存成功才跳到成功页。
- 草稿：发布表单自动保存，再次打开会恢复。发布成功后清除草稿。
- 状态：示例和他人的记录不能更新；已完成记录保留在列表中供筛选查看。

## 自动测试

运行网页无需 Node。开发者运行测试需安装 Node.js 24 或兼容 `node:test` 的版本，无需 `npm install`。

在本目录打开终端，运行：

```powershell
node --test tests/domain.test.cjs tests/storage.test.cjs
```

成功输出应包含 `tests 28`、`pass 28`、`fail 0`。测试不会修改网页里已保存的记录：存储测试使用独立的内存替身。

白盒测试覆盖合法与非法输入、长度边界、日期、关键词归一化、组合筛选、本人权限、幂等更新、文本转义、重新读取、损坏数据和保存失败。自动测试不替代浏览器走查。
